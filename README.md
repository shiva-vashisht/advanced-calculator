# 🧮 Advanced Calculator

A command-line calculator built using Python that performs multiple mathematical operations with a clean and user-friendly interface.

---

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division (with zero handling)
* 🔢 Power calculation
* 🧮 Modulus operation
* 🔁 Continuous calculation using previous result
* ❌ Error handling for invalid inputs

---

## 🛠️ Tech Stack

* Python
* VS Code

---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/shiva-vashisht/advanced-calculator.git
```

2. Navigate to the project folder:

```bash
cd advanced-calculator
```

3. Run the program:

```bash
python calculator.py
```
